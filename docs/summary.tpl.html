6mer ASO を鋳型上でつなぐ
——リンカー接続位置の 3 方式を比べる

CGGGGC の 6mer ASO 2 本を C9orf72 リピート RNA の上に並べ、テトラジン／シクロプロペンの IEDDA 反応で連結する設計。リンカーをどこから生やすかで反応性が 107 倍変わる。RDKit で分子を、実測 RNA 結晶構造から組んだ A 型二重鎖で鋳型を扱い、3 つの接続方式を同じ物差しで比較した。

4 つの問いへの答え

① 0 gap で進むか

43.6 秒

ホスホトリエステル型なら 1 µM で半減期 43.6 秒。24 本の鋳型すべてで反応配座に届いた。

② 鋳型 ON / OFF 差

2.4×104 倍

1 µM で鋳型ありは 43.6 秒、なしは 12.3 日。99% 進むまでに非鋳型反応は 0.019% しか進まない。

③ 3 方式の勝敗

C > B >> A

C ホスホトリエステル、B 塩基 C7、A 末端リン酸。A は 0 gap で反応配座に一度も届かない。

④ C を選んだ理由

100 %

立体的に無理がなく（ひずみ 2.5 kcal/mol）、推定のブレも 3 倍以内。B は前提次第で答えが 104 倍動く。

一行でいうと

「どこにハンドルを付けるか」は「どれだけ長いリンカーを使うか」より効く。A 型二重鎖の主溝は狭く（塩基 C7 型）、ニックの隙間はもっと狭い（末端リン酸型）。骨格リン酸をホスホトリエステル化して外向きの非架橋酸素から生やすと、アームは二重鎖の外側の開けた空間に出るので、短いリンカーのままで 0 gap が成立する。

A と C はアーム自体は同じ

末端型（A）と三エステル型（C）で使うアームの原子の並びは同一で、違うのは根元のリン酸がどこにあるかだけ。それだけで 0 gap の成否が分かれる、というのがこの比較の要点です。

06

結果 ③：3 方式それぞれ、何が起きていたか

A 末端ホスホジエステル型 ── 0 gap で「隙間の取り合い」になる

0 gap では、上流 ASO の 3' 末端から出るリンカーの根元と、下流 ASO の 5' 末端が、本来 1 個のリン酸が入るはずの同じ空間を奪い合う。その結果アンカー間距離が 4.20 Å しかないのに向きは 104°（＝互いにそっぽを向く）となり、届かせるには 15.7 kcal/mol のひずみが要る。ギャップを 1 塩基空けた途端に 100% 到達に変わることから、これは「リンカーが短い」のではなく「置き場所がない」問題だと分かる。

B 塩基 C7 型 ── 進むが、主溝が狭く、答えが安定しない

7-deaza-G の C7 は A 型二重鎖の主溝の底にある。A 型 RNA の主溝は B 型 DNA と違って深く狭いため、アームの置き場所が限られる。実際、テトラジン側アームが立体的に許される配置は 0.60% しかない（シクロプロペン側は小さいので 7.27%）。それでも 24 本中 11 本（46%）は反応配座に届き、1 µM で半減期 23 分と、実験としては十分成立する速さになる。

修飾位置を 6 通り振ると、到達率は 50–81%、EM_steric は 6×10⁻² – 2×10⁻¹ M の間で動いた。位置を変える効果はリンカーを 1–2 原子伸ばす効果よりずっと大きい。ただし下表のとおり「どの指標で見るか」で順位が入れ替わる（(3,4) は到達率・EM_steric では (2,5) を上回るのに、ひずみ込みの EM_boltz では下回る）。この不安定さが B の弱点。

(2,5) と (3,4) の読み方

(2,5)は接合部から最も遠い G を選ぶ配置。Δ = 3 と間隔が狭く、ひずみ 5.4 kcal/mol・到達率 50% と 6 通り中もっとも窮屈になる。
(3,4)は接合部をまたいで最も近い G どうしを選ぶ配置。Δ = 5 に広がり到達率は 62%、EM_steric は 2.4 倍良い。ただしアーム自体の内部ひずみを勘定に入れる EM_boltz では 3.15e-4 と (2,5) の 5.01e-4 を下回る。
つまり (3,4) の方が「空間的には楽」だが「アームに無理な配座を要求する」。B の中で選ぶなら実際にはどちらでもなく (3,5)（到達率 81%、EM_steric 2.14e-1、EM_boltz 3.28e-3）が最良でした。

判定：0 gap で機能はする。ただし ⓐ 修飾位置の選び方に強く依存し、ⓑ 7-deaza-G という非天然塩基を 2 つ導入する合成コストがかかり、ⓒ 主溝を埋めるため他の因子（タンパク質結合など）への影響が読みにくい。

C ホスホトリエステル型 ── 二重鎖の外側に出るので詰まらない

1–2 番目と 5–6 番目をつなぐ内部リン酸を三エステル化し、非架橋酸素からアームを伸ばす。この酸素は螺旋軸から見て P より 1 Å 外側を向いているため、アームは溝でもニックでもなく開けた溶媒側に出る。結果、立体的に許される配置は Tz 側 23.5%・Cp 側 29.7%（B の 40 倍）、向きの角度も 51° と互いを向き、ひずみは 2.5 kcal/mol まで下がる。24 本すべてで到達し、3 つの EM 指標が 2.6–4.9 × 10⁻² M に揃う。

07

結果 ④：なぜホスホトリエステル型を最適と考えたか

  1. 0 gap が「ギャップを空けずに」成立する唯一の方式だった

    末端型は 0 gap で到達率 0%。塩基 C7 型は 46%。三エステル型だけが 24 本すべてで到達する。C9orf72 リピートを隙間なく埋めていく設計方針と両立するのはこれだけ。

  2. アームが二重鎖の「外側」に出るので、狭い場所の取り合いが起きない

    主溝（B）でもニックの隙間（A）でもなく、非架橋酸素は溶媒側を向く。立体的に許される配置が 23–30% と、B の 0.6% に対して桁で違う。これはリンカーを伸ばして解決する種類の問題ではなく、根元を移して解決する問題だった、というのが今回いちばんの学び。

  3. 払うひずみが小さい

    2.5 kcal/mol。室温の熱ゆらぎ（1 個ぶん 0.6 kcal/mol）で越えられる。A の 15.7 kcal/mol は室温では越えられず、B の 4.9 kcal/mol は越えられるが確率が落ちる。

  4. 推定のブレが小さい ＝ 計算の結論として信用できる

    下図。同じ設計に対して「数え方を変える」「別の鋳型スナップショットを使う」「反応の判定基準を厳しく／緩くする」「経験パラメータを振る」と答えがどれだけ動くかを見た。B は最大 2 万倍動き、条件によっては到達率 0 まで落ちる。C は最大でも 3.2 倍。C の「速い」は前提の選び方に依存しない結論。

  5. 合成が素直で、非天然塩基を増やさない

    7-deaza-G を 2 個入れる必要がない。三エステル化は P 上の不斉が生じるが、4 種のジアステレオマーすべてが 100% 到達（表 9）なので分離不要。

  6. 鋳型 ON/OFF 比が最大になる

    鋳型上が速いほど、非鋳型反応が走り出す前に反応を切り上げられる。C は 1 µM で 2.4 万倍、0.1 µM なら 15.9 万倍（表 6）。B（半減期 23 分）だと同じ濃度でも切り上げが遅くなり選択性が落ちる。

08

この計算で言えること・言えないこと

  • 言えること：3 方式の相対比較。同じ鋳型スナップショット・同じ判定基準で比べているので、順位と桁の差は信頼できる。
  • 言えないこと：半減期 43.6 秒という絶対値。これは k₂ = 0.65 M⁻¹s⁻¹（別の基質での実測値）をそのまま使った推定なので、実際のテトラジン・シクロプロペンの置換基によって数倍は動く。
  • 扱っていないこと：(C4G2)n が形成する G-カルテットなどの高次構造、水分子の明示的な扱い、リピート RNA 上での ASO の滑り（レジスター選択）、細胞内の RNA 結合タンパク質。鋳型は「A 型二重鎖の熱ゆらぎ」で近似している。
  • 次にやるべき実験：まず 0.1–1 µM、10 分の条件で、鋳型 RNA あり／なしの連結収率を LC-MS で比較。ON/OFF 比が 10³ を超えれば計算どおり。非鋳型対照は必ず同じ時間で切ること（24 時間置くと表 6 のとおり非鋳型が追いついてくる）。
用語

用語と記号

EM実効モル濃度
鋳型につながれた 2 つの反応基が「実質どれくらいの濃度でそばにいるか」。単位は M。EM = 0.05 M なら 50 mM 相当。実験の ASO 濃度（µM）と比べて桁がいくつ大きいかが、鋳型効果の大きさ。
EM_steric届きやすさ重視
「RNA とぶつからない配置」だけを数え、その中で反応配座に入る割合から出した EM。アーム内部のひずみは数えない ＝ いちばん甘い見積り。
EM_unif中間
RNA との相互作用エネルギーで重みをつけて数えた EM。配座どうしは等重み。
EM_boltzひずみ込み
アーム自身の MMFF94 エネルギーも含めて、ボルツマン分布（エネルギーが高い配置ほど現れにくい、という統計力学の重みづけ）で数えた EM。いちばん辛い見積り。3 つが近い値なら推定が安定している、という読み方をする。
NAC反応できる配置
near-attack conformation。テトラジンとシクロプロペンが「あと一歩で結合ができる」幾何配置。距離・角度・ずれの 5 条件で判定（図 2）。
ひずみstrain
その反応配座に持っていくために払うエネルギー（kcal/mol）。0.6 が室温の熱ゆらぎ 1 個ぶん。10 を超えると室温では実質起きない。
到達率reachable
用意した鋳型スナップショット（熱ゆらぎで揺らした二重鎖）のうち、両アームが無理なく NAC に届いたものの割合。
k₂二次速度定数
テトラジン + シクロプロペンが溶液中でぶつかって反応する速さ。0.65 M⁻¹s⁻¹（doi:10.1002/chem.201304225）。「鋳型上の速さ = k₂ × EM」が基本式。
θ_AB両方が乗っている確率
ASO 2 本が同時に鋳型に結合している確率。Turner 2004 パラメータから求めた Kd と ASO 濃度で決まる。
Δハンドル間隔
接合部をまたぐ 2 つのハンドルが、鎖に沿って何塩基離れているか。塩基 C7 型で位置を振るときの指標。
gapギャップ
ASO 2 本の間に残る、どちらにも覆われていない鋳型塩基の数。本設計の目標は gap = 0。
傍観アームbystander
1 本の ASO に 2 個入っているハンドルのうち、その接合部の反応に使われない方。周りを混雑させる効果を見るために置く。
